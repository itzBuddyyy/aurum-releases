# Aurum releases

Installers for **Aurum** tester copies (Windows). No source code here.

- Each release carries `Aurum-Tester-<version>-windows-x64-setup.exe` and a signed `latest.json`.
- Tester copies check this page for updates by themselves (*About* → *Check for updates*) and only
  install files whose checksum is signed by the developer.
- A tester copy needs a personal key for your PC: open Aurum, copy the **Machine ID**, send it to
  the developer and paste the key you get back. The key never expires.
